# Security Policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could cause unintended file removal, privilege escalation or exposure of user data.

Email `dangvanhai13091989@gmail.com` with:

- affected version and macOS version;
- reproduction steps;
- the paths or cleanup rule involved;
- expected and actual behavior.

Do not include private user files. Acknowledgement is normally sent within seven days.

## Security model

The Direct edition runs without App Sandbox but as the current user. Full Disk Access remains optional and user-controlled. ApexUninstaller does not require root access and moves selected items to Trash. A centralized safety policy blocks destructive roots and protected system locations.
