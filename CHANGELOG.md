## 1.0.1 - 2026-09-04

- Add a separate hardened `DirectRelease` configuration without App Sandbox.
- Allow the Direct edition to scan the user's Library without a folder picker.
- Add optional Full Disk Access guidance in Direct edition settings.
- Add a centralized removal safety policy for privileged filesystem access.
- Prepare GitHub Releases, open-source contribution and sponsorship files.
- Improve window reopening behavior.
- Improve App Store permission descriptions and review compatibility.
